## 更新内容

- 新增「访客信息样式」设置：底部 IP 条与左下角详情卡片内容重复，现在同一时间只显示一种。默认 auto 在超宽屏显示卡片、其余屏幕显示 IP 条，也可固定为 bar 或 card；「显示访客信息」仍可整体关闭。
- 节点卡片的流量项悬停时显示距离下次流量重置的天数（#14）。
- 同一行的节点卡片保持等高，没有备注的卡片不再比相邻卡片短。
- 修复延迟色条等数据提示气泡被节点卡片边缘截掉的问题，气泡也会自动避开屏幕边缘。
- 离线卡片的「离线」文字与离线时间加上背景色阴影，不再与下方淡化的数据叠在一起看不清。
- 首页切换全部节点、收藏、总流量等快捷筛选时复用已有卡片：仍在列表中的卡片平滑移动到新位置，只有新增和移除的卡片淡入淡出，不再整体闪烁重排。
- 节点详情切换时间区间时，加载遮罩延迟出现并淡入淡出，快速返回的请求不再闪一下；加载中只轻微压暗旧图表，不再整片模糊。
- 更新预览图。

## 安装

下载下方的 `theme.tar.gz`，在极简探针后台「主题」中上传并启用；已安装用户也可通过「从 GitHub 更新」升级。
